J.A.R.V.I.S. — Personal AI Assistant

A JARVIS-inspired personal assistant I talk to by voice. It syncs my Canvas coursework, manages tasks, calendar and reminders, and researches stocks, ETFs, crypto and gold with explainable Buy / Hold / Avoid ratings tuned to my risk profile. A scheduled monitor sends phone and email alerts. Built around an agentic Claude tool-use loop.

  • Python
  • Claude API
  • Streamlit
  • Postgres
  • pandas
